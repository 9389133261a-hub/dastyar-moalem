# دستیار معلم دبستان

اپلیکیشن اندروید مدیریت کلاس برای معلمان دبستان.

## ویژگی‌های نسخه اولیه
- برنامه کلاسی
- حضور و غیاب
- ثبت نمرات
- دفتر تلفن
- مدیریت تکالیف
- تقویم رویدادها
- ساختار Freemium (رایگان + پرمیوم)

## نحوه اجرا
1. Flutter SDK را نصب کنید
2. در پوشه پروژه دستورات زیر را اجرا کنید:
```bash
flutter pub get
flutter run
```
